# Maggie Choi — Personal Portfolio

A responsive personal portfolio website designed around strategic partnerships, business development, and executive engagement.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static web server.

## Customization

- Update the contact email in `index.html`.
- Replace the monogram-style profile placeholder in `.portrait` with a professional image when available.
- Update the LinkedIn URL in the Insights section.
